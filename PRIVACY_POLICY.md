# Privacy Policy — Fuzzy Links

Last updated: August 21, 2026

Fuzzy Links is a keyboard-navigation browser extension. It processes webpage structure locally in the browser so it can identify interactive controls such as links, buttons, menus, and form controls.

## Data collection

Fuzzy Links does not collect, sell, transmit, or share personal data, browsing history, webpage content, form values, analytics, or usage telemetry with the developer or any third party.

## Local processing

The extension reads the current webpage DOM locally to identify visible interactive elements and provide fuzzy search, spatial keyboard navigation, highlighting, activation, and contextual scrolling. This processing occurs on the user's device.

## Settings

The user-selected activation shortcut is stored using Chrome's `storage.sync` API. This setting may be synchronized by the browser through the user's Chrome profile. Fuzzy Links does not operate or receive that synchronization service.

## Form fields

Fuzzy Links intentionally uses labels, placeholders, names, and ARIA metadata to describe form controls. It does not use the current contents typed into form fields as fuzzy-search labels.

## External services

Fuzzy Links does not use external servers, advertising services, analytics providers, or remote code.

## Changes

If the extension's data practices materially change, this privacy policy will be updated before publishing the corresponding extension update.

## Contact

For questions or security reports, use the public support/contact method listed on the Fuzzy Links GitHub repository.
